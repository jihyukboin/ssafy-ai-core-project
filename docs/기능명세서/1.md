# AI PJT 기능명세 및 요구사항 대조

## 범위

국내 KOSPI·KOSDAQ 대표 종목의 시가총액 상위 100개 기업을 대상으로 기업정보·공시·설명 문서의 근거를 제공한다. 투자 권유나 목표 주가 예측은 제공하지 않는다. 로그인, 사용자 계정, 대화 영구 저장은 사용자 요청에 따라 제외한다. F2009의 항목별 대화 구분은 현재 페이지 메모리에서 제공하며 새로고침하면 초기화한다.

## 도메인과 데이터

- 항목: 기업 100개. 시세 스냅샷 기준일 2026-10-20.
- 외부 문서: OpenDART에서 확보한 공시 본문 360건 및 질문에 따라 선별한 한국어 위키백과 문서.
- 출처·이용 조건: `data/kr_stocks/README.md`. 수집 원문·로고·색인은 로컬 전용이며 저장소에서 제외한다.
- 근거가 필요한 질문: 사업 부문은 무엇인가, 공시에서 확인되는 자회사 실적은 얼마인가, 특정 시세 기준일의 시가총액은 얼마인가.
- 안내: “이 답변은 공시·기업정보를 설명하는 교육용 자료이며, 투자 권유나 전문가의 투자 조언을 대신하지 않습니다.”

## API

- `GET /health`: 데이터 로딩 상태.
- `GET /api/companies?q=&market=`: 기업 목록.
- `GET /api/companies/{stock_code}` 및 `/logo`: 기업 상세·WebP.
- `GET /api/rag/status`: 키 존재 여부(키 값 제외), 색인 건수, 기준일, 준비 상태, 검색 설정.
- `POST /api/chat`: `{stock_code, question, mode: "chat"|"summary", history?: [{role,text}], search_method?: "mmr"|"similarity", top_k?: 1..15}`.
- `POST /api/explore`: `{question}`. `/api/chat`에서 기업 없이 질문해도 탐색으로 처리.

채팅/탐색 응답은 `application/x-ndjson`이며 한 줄에 하나의 JSON 이벤트다.

```json
{"type":"status","stage":"retrieving","message":"근거를 검색합니다."}
{"type":"result","kind":"answer","answer":"설명 [근거 1]","sources":[{"number":1,"title":"제목","url":"https://...","type":"dart_disclosure","excerpt":"원문 발췌"}],"disclaimer":"금융 안내","metrics":{"elapsed_seconds":4.2}}
```

탐색 결과는 `kind: "companies"`, `items`에 검증된 기업과 근거·선정 이유를 반환한다. 처리 오류는 `type: "error"`, 주기적 연결 유지는 `type: "heartbeat"`다. 형식 오류는 422, 없는 기업은 404, 키·색인 준비 오류는 503이다. `PUT /api/chats`와 로그인·대화 저장용 세션 쿠키는 제공하지 않는다.

## 제외 및 한계

- 실시간 주가/공시 전수 갱신·투자 의사결정·로그인·영구 대화 저장은 범위 밖이다.
- 후보 탐색은 확보한 100개 기업에서 최대 10개를 제시한다.
- 원문을 처음 색인하는 질문은 문서 크기와 외부 API 상태에 따라 시간이 달라진다.
- 실제 인용 번호·존재 여부는 코드로 검증하지만 문장 전체의 사실 정확성은 원문 대조가 필요하다.
- 상호 체크리스트는 실제 다른 교육생의 검증 후 작성해야 하며 수행하지 않은 상호 점검은 완료로 기록하지 않는다.
