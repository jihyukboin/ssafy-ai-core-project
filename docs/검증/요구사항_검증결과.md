# 요구사항 분석 및 검증 결과

검토일: 2026-10-21. 로컬 제공 요구사항정의서의 F2001~F2016, NF2001~NF2007 및 4·6장의 제출물을 대상으로 검토했다. 비공개 원문은 저장소에 복사하지 않는다.

필수 12개와 선택 심화 4개의 구현을 확인하고 아래 결함을 보완했다. 자동 테스트와 로컬 데이터 검증은 통과했다. 변경 후 실서비스 화면 재점검, 최초 요청 성능 측정, 실제 교육생 간 상호 점검, 별도 제공 공식 셀프 체크리스트 확인은 남아 있으므로 **제출 요건 전체 완료로 판정하지 않는다.**

## 발견한 부족한 부분과 보완

| 문제 | 영향 | 반영 내용 |
|---|---|---|

## 이번 테스트 결과표

서버를 실행·재시작하지 않았다. FastAPI 검증은 소켓을 열지 않는 TestClient, Chroma 회귀 검증은 임시 디렉토리에서 수행했다. 이번 검증에서는 외부 LLM을 호출하지 않았다.

| 검증 | 결과 |
|---|---|
| 백엔드 unittest | 25개 통과. 수집·캐시·재시도·갱신·필터·근거·LangGraph·API 검증 |
| 프런트 `npm test` | 8개 통과. SSR 초기 상태·기업 URL·메시지 분리·HTML 주입 방어 등 |
| 프런트 `npm run build` | 클라이언트 및 SSR 번들 빌드 성공 |
| 실제 데이터 검증 | 23개 검사 모두 통과. 기업 100개·공시 목록 988건·공시 본문 360건·사업 발췌 100건·WebP 로고 100개 |
| 실제 로컬 색인 조회 | `stock_meta` 100건·`disclosure_docs` 3,626청크. 현재 스냅샷의 ID·기준일·본문 해시 일치, 외부 출처 유형 DART·위키백과 모두 존재 |
| 명세 버전 의존성 확인 | `pip install --dry-run -r backend/requirements.txt` 의존성 해석 성공 |
| 명세 버전에서 회귀 검증 | 기존 실행 환경을 변경하지 않고 임시 `/tmp/core-spec-deps`에 Pydantic 2.13.5·pydantic-core 2.46.5·LangSmith 0.10.17·langchain-community 0.4.2 등을 설치하고 우선 로드하여 백엔드 테스트 통과 |
| 청킹 설정 실측 | 실제 SK스퀘어 보고서로 4개 조합 비교. [파이프라인 설계](../RAG_파이프라인.md) 참조 |
| 인증키 노출 점검 | Git 추적 파일 및 생성 데이터에서 로컬 인증키 값 발견 0개 |
| 변경 파일 검사 | Python 구문 분석 및 `git diff --check` 통과 |

재현 명령(프로젝트 루트):

```bash
PYTHONPATH=.:backend backend/.venv/bin/python -m unittest discover -s backend/tests -v
backend/.venv/bin/python scripts/validate_stock_dataset.py
backend/.venv/bin/python -m pip install --dry-run -r backend/requirements.txt
cd frontend
npm test
npm run build
```

로컬 `.venv`는 기존 서버 환경을 유지했다. 명세 버전은 `backend/requirements.txt`를 기준으로 설치한다. 임시 패키지를 우선 로드한 검증은 `PYTHONPATH=/tmp/core-spec-deps:.:backend`로 실행했다.
